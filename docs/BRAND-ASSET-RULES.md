# Brand asset rules

## Identity roles

- Use **Hospitality Operations Platform** for the collection, company, partnerships, and portfolio surfaces.
- Use **Property** for the first property's guest-facing experience.
- Use the botanical mark alone only when the identity is already obvious.
- Use the RK monogram for small property applications, not as the collection master mark.

## Location neutrality

Do not place a city, region, country, address, or property count inside a core logo file. Location belongs in contextual property content, wayfinding, booking details, and metadata when those facts are confirmed.

## Clear space

Keep clear space around a lockup equal to at least the height of its botanical mark. Do not place copy, borders, photography, or another logo inside that area.

## Alteration

Do not stretch, rotate, outline, recolor arbitrarily, add shadows, or rebuild the wordmark. Use the supplied SVG source whenever possible.

## File map

- `hospitality-operations-platform-wordmark.svg`: collection master.
- `primary-property-lockup.svg`: primary property lockup.
- `primary-property-horizontal.svg`: wide property format.
- `rk-monogram.svg`: compact property mark.
- `botanical-mark.svg`: supporting emblem.
- `botanical-pattern.svg`: repeating surface.
- `favicon.svg` and `icons/*`: digital compact marks.


## Photography and concepts

Generated interiors establish material, light, and composition direction only. Do not present them as documentary property photography. Keep the visual-concept disclosure visible until each image is replaced with an approved real photograph, then update the centralized media record rather than hardcoding a replacement inside JSX.
