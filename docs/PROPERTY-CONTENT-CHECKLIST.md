# Provider property content checklist

Public property facts must come from the provider or another explicitly verified source. They must never be inferred from generated imagery, competitors, map guesses, or neighboring listings.

## Configure per property

- Property name and type.
- Verified location/address and official map profile.
- Verified contact channels.
- Bedroom/bathroom counts where known.
- Maximum guest capacity where confirmed.
- Bookable inventory model and unit structure.
- Public amenities and accessibility features.
- Rates, taxes, deposits, extra-person charges, and minimum stay.
- Check-in/check-out times.
- Booking, cancellation, refund, damage, smoking, pet, visitor, and quiet-hours policies.
- Arrival guidance, parking/access, landmarks, and recommendations.

Unknown values should remain empty. The management system must not manufacture defaults for business facts.

## Operational data starts empty

The upstream platform does not create example guests, reservations, payments, expenses, availability blocks, tasks, or revenue. Providers create operational records only from real operations.
